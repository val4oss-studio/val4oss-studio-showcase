**10.2 — Périmètre du debug.** Le debug mensuel couvre la **correction d'anomalies**
d'un site existant et fonctionnel. Il **exclut** : le développement de nouvelles
fonctionnalités, la refonte graphique, la migration de plateforme, et la correction

**10.3 — Durée et résiliation.** L'abonnement est conclu sans engagement de durée,

n'est due. Les sommes correspondant au mois entamé restent acquises.

**10.4 — Réversibilité.** À la résiliation, le Prestataire remet au Client, sans frais
et sous **30 jours** : le code source à jour, un export complet de la base de données,
les fichiers médias, et la documentation de déploiement. Le Prestataire assiste le
Client dans le transfert du nom de domaine.

Les données sont conservées **90 jours** après la fin de l'abonnement, puis supprimées
de manière irréversible, sauvegardes comprises.

est possible à tout moment, sans frais autres que ceux du registrar.

continuité du service, sans garantie de disponibilité chiffrée (SLA). Les

sont programmées.

**10.7 — Révision tarifaire.** Les tarifs peuvent être révisés une fois par an, avec
un préavis écrit de **60 jours**. Le Client dispose alors d'un droit de résiliation
